## How each run is done

- Client: Claude Desktop, server configured as `uv --directory <repo> run main.py`.
- One new chat per question. Paste the question text only.
- **Correct**: Y only if the final answer matches the expected answer exactly.
- **Tool calls**: every tool-call block in the chat, including failed calls and retries.

## Before vs after

Accuracy and tool-call counts barely moved; what changed is where the work happens.

- **Accuracy** stayed at 10/10. The baseline was already perfect, so this eval cannot
  show an accuracy gain.
- **Tool calls**: 18 before, 17 after (median 2 both times). Only Q6 changed (3 -> 2).
- **No client-side computation in the new run.** Before, 2 of the 18 calls were
  bash_tool runs where Claude computed moving averages itself from raw prices (Q4, Q5),
  and in Q7 to Q9 it worked out margins, debt-to-equity and free cash flow from raw
  statements to avoid the buggy metric tools. After, every calculation came from a
  Tearsheet tool and Claude quoted the server's figures.
- **Unchanged**: Q1 and Q3 still answered the split part from model knowledge without
  calling the splits tool, and Q10 still computed the CAGR by hand rather than calling
  tearsheet_calculate_growth_rates.
