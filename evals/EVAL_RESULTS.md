# Evaluation results

Questions and expected answers: `evaluation.xml` (generated by `evals/ground_truth.py`).

## How each run is done

- Client: Claude Desktop, server configured as `uv --directory <repo> run main.py`.
- One new chat per question. Paste the question text only.
- **Correct**: Y only if the final answer matches the expected answer exactly.
- **Tool calls**: every tool-call block in the chat, including failed calls and retries.
- **Tokens**: Claude Desktop does not report them, so `n/a`.

### Baseline summary

- Accuracy: 10/10.
- Tool calls: median 2 (range 0 to 3, total 18). Two of the 18 were bash_tool runs (Q4, Q5), not Tearsheet tools.
- Tokens: not reported by Claude Desktop.
- In Q4 and Q5, Claude fetched prices and computed the indicators in bash_tool instead of passing price rows into mcp_backtest_strategy or mcp_calculate_technical_indicators. In Q8 and Q9 it computed the ratios from raw statements, so the old metric bugs did not affect the answers. In Q1 and Q3 it answered from its own knowledge instead of calling retrieve_splits.
