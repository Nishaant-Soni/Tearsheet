# Evaluation results

Questions and expected answers: `evaluation.xml` (generated by `evals/ground_truth.py`).

## How each run is done

- Client: Claude Desktop, server configured as `uv --directory <repo> run main.py`.
- One new chat per question. Paste the question text only.
- **Correct**: Y only if the final answer matches the expected answer exactly.
- **Tool calls**: every tool-call block in the chat, including failed calls and retries.
- **Tokens**: Claude Desktop does not report them, so `n/a`.
